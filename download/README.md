# 📸 Screenshots & Audit

Reference material for the **Skare Store** project.

| File | What it shows |

The security audit was produced during the hardening phase and is the source of
the controls documented in the main [README](../README.md#-الأمان) — auth hardening,
rate limiting, security headers, Zod validation, audit logging, and safe uploads.
